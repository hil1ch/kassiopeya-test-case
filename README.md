# Kassiopeya Test Case

Проект представляет собой одностраничную карточку товара с описанием, выбором фасовки, галереей изображений и модальным окном для увеличения фото.

## Описание проекта

Это статический HTML/CSS/JavaScript проект, созданный для демонстрации карточки продукта.

В проекте используется чистый JavaScript без внешних библиотек и сборщиков, поэтому его легко открыть и быстро запустить локально.

## Что входит в проект

- `index.html` — структура страницы и контент товара;
- `style.css` — стилизация интерфейса и адаптивный layout;
- `main.js` — логика модального окна и выбора изображений;
- `public/` — изображения и иконки, используемые на странице.

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)

## Требования

Для запуска проекта достаточно:

- современного браузера;
- локального веб-сервера или встроенного Python HTTP-сервера.

## Как запустить проект

Перейдите в директорию с проектом и откройте файл `index.html` прямо в браузере.
